# Smart Management Demo

Run the local demo from this directory:

```sh
python3 serve.py
```

Open <http://127.0.0.1:8765/#live-room/1>. The local server supports byte-range requests so the two MP4 recordings can be played and scrubbed together.

The two MP4 recordings are tracked with Git LFS. Install Git LFS before cloning the repository to download the videos with the project.
